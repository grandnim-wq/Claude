# 한국 외식 브랜드 벤치마킹 조사

## 목적
/ 의뢰인: 외식 프랜차이즈 20년 경력 임원. 2026-12-01부터 아모제 신규 브랜드 기획 부서 임원.
/ 목표: 아모제 3개 브랜드의 리뉴얼, 신규 전환에 참고할 국내 브랜드를 카테고리별 10~20개 조사한다.
/ 기준일: 2026-11-24.

## 카테고리와 출발 후보 (사용자 지정)
/ 한식(자문밖 대응): 솥밥, 볶음, 찌개와 탕으로 구성된 반상형 브랜드. 출발 후보 솔솥, 담솥, 본우리반상(메인 타깃), 해옥담, 도꼭지.
/ 패스트캐주얼(카페아모제 대응): 요즘 뜨는 보울, 샐러드, 포케, 멕시칸 브랜드. 출발 후보 치폴레(국내 진출 여부 확인), 더타코부스, 샐러디, 포케올데이, 알라보(메인 타깃).
/ 오므라이스(오므토토마토 대응): 오므라이스를 기반으로 한 화제 브랜드. 출발 후보 오밀 성수, 을지다락, 송리단취향, 빠레트한남, 이쿠라, 데이릿.
/ 출발 후보 외에도 같은 성격의 브랜드를 찾아 카테고리당 10~20개를 채운다.

## 유형 (벤치마킹 포인트)
/ 장사: 대기 줄, 매장 확장 속도, 매출이나 가맹점 수 증가
/ 유명: 원조, 미디어 노출, SNS 화제성
/ 특별: 포맷, 조리 시연, 메뉴 구조, 공간 연출

## 브랜드별 조사 항목
/ 브랜드명, 운영사(법인명), 론칭 연도
/ 매장수: 전체, 직영, 가맹. 기준 시점과 출처
/ 운영 형태: 직영 / 가맹 / 직영+가맹
/ 가맹 브랜드면 공정위 가맹사업 정보공개서 수치(가맹점 수 추이, 가맹점 평균 매출, 가맹비와 인테리어 비용)를 찾을 수 있는 만큼 찾는다. 원문을 못 열면 기사나 검색 요약으로 표시한다
/ 시그니처 메뉴와 가격, 메뉴 구성(카테고리 구조), 객단가대
/ 입지 유형: 백화점, 쇼핑몰, 오피스, 대학가, 로드숍, 공항, 역사
/ 브랜드 특징, 벤치마킹 포인트, 아모제 시사점(가져올 것, 그대로 안 되는 것)
/ 공식 사이트 또는 공식 인스타그램 URL

## 근거 규칙
/ 주장마다 근거 등급을 붙인다. [원문] 페이지 직접 확인, [검색요약] 검색 결과 요약에서만 확인, [추론] 판단.
/ 검증하지 못한 숫자는 사실처럼 쓰지 않는다. 기사 숫자는 기사 날짜를 적는다.
/ 폐점, 브랜드 매각, 리브랜딩 정보가 있으면 적는다.

## 산출물
/ 마크다운: benchmark/korea/<카테고리>.md. 맨 앞에 요약표, 그 뒤 브랜드별 상세, 끝에 확인 필요 사항.
/ JSON: benchmark/korea/<카테고리>.json. 엑셀 변환용. 배열, 매장수 많은 순 정렬. 각 원소 필드:
  brand(한글 브랜드명), operator(운영사), launched(론칭 연도 문자열 또는 "-"), stores(정수 또는 null), stores_note(직영 n, 가맹 m 같은 짧은 문자열), operation("직영"|"가맹"|"직영+가맹"|"확인 필요"), type(["장사","유명","특별"] 중 해당), signature(시그니처 메뉴 한글, 부가설명 없이), menu_structure(메뉴 구성 한 줄), price(객단가대 예: "1만~1.5만원"), location(입지 유형 짧게), feature(브랜드 특징 30자 안팎 한 줄), point(벤치마킹 포인트 30자 안팎 한 줄), implication(아모제 시사점 한 줄), url(공식 사이트나 인스타그램 URL 또는 null), evidence(매장수 근거 등급 "[원문]" 등), main_target(true|false)
/ 글머리 기호는 "/"를 쓴다. 문서 논조는 깎아내리지 않고 사실만 남긴다.
