# 간사이 외식 브랜드 벤치마킹 조사

## 목적
/ 의뢰인: 외식 프랜차이즈 20년 경력 임원. 2026-12-01부터 아모제 신규 브랜드 기획 부서 임원.
/ 현장 방문: 2026-11-25(수)~11-30(월), 고베와 오사카.
/ 목표: 아모제 3개 브랜드의 리뉴얼 또는 신규 전환에 참고할 일본 외식 브랜드를 고르고, 브랜드 단위로 조사해 현장 방문 리스트를 만든다.

## 아모제 대응 브랜드 (확정 사실, 임의로 바꾸지 않는다)
/ 자문밖(한식): 인천공항 T2 4층 안쪽, 약 80평. 40~50대 고객 유입. 식사(탕, 한상, 비빔밥, 냉면), 저녁 안주, 게장. 솥밥 양호, 찌개와 볶음류 보완 필요.
/ 오므토토마토(일식, 오므라이스): 강남본점 기준. 방향은 시그니처 메뉴와 조리 과정을 보여주는 시연형 전문점. 참고 모델은 오사카 도톤보리 DEARBROS.
/ 카페아모제(델리, 패스트캐주얼): 시티마르쉐와 판매 상품이 같고 백화점 식품관 내 입지가 줄고 있다. 방향은 보울, 랩, 샐러드 패스트캐주얼 전문점.

## 후보 선정 기준
벤치마킹 포인트는 셋 중 하나 이상이어야 한다. 브랜드마다 해당 유형과 근거를 적는다.
/ A 장사가 잘된다: 줄, 매장 확장 속도, 실적 공시
/ B 유명하다: 원조, 미디어 노출, 관광 명소화
/ C 특별하다: 포맷, 조리 시연, 메뉴 구조, 공간 연출

추가 조건
/ 오사카 또는 고베에 방문 가능한 매장이 있어야 한다. 교토에만 있으면 "참고"로만 둔다.
/ 후보 8~10개를 조사하고, 아모제 관점의 우선순위를 매긴다.
/ "일본에서 잘 되는가"보다 "아모제 입지(공항, 백화점 식품관, 도심 상권)에서 돌아가는 포맷인가"를 우선순위 판단에 반영한다.

## 브랜드별 조사 항목
/ 브랜드명(일본어 원문, 한국어 표기), 운영사, 창업 연도
/ 매장 수: 전국, 간사이, 기준 시점, 출처
/ 입지 유형: 노면, 상업시설, 백화점 식품관(데파치카), 역사, 공항 입점 여부
/ 포맷: 좌석 매장, 테이크아웃, 이트인 겸용, 푸드코트
/ 시그니처 메뉴와 가격(엔, 세금 포함 여부 표기), 객단가대
/ 조리 시연, 공간 연출, 주문 방식에서 특별한 점
/ 벤치마킹 포인트(A/B/C)와 근거
/ 아모제 시사점: 가져올 수 있는 요소, 그대로 옮겨지지 않는 요소와 이유
/ 방문 추천 매장 1~2곳: 매장명, 주소, 가까운 역, 영업시간, 정기휴무, 예약 가능 여부, 피크 시간 메모
/ 출처 URL

## 근거 규칙 (반드시 지킨다)
/ 모든 주장 옆에 근거 등급을 붙인다. [원문] 페이지를 직접 열어 확인, [검색요약] 검색 결과 요약에서만 확인, [추론] 판단.
/ 매장 수는 공식 매장 목록 페이지나 운영사 IR 원문에서 확인한 경우에만 숫자로 쓴다. 그 외에는 "확인 필요(검색요약상 약 N)"로 쓴다.
/ 검증하지 못한 숫자를 사실처럼 쓰지 않는다. 폐점이나 이전이 의심되면 표시한다.
/ 타베로그, 구글맵 등에서 수집이 막히면 공식 사이트, 운영사 IR, PR TIMES, 일본 언론 기사를 쓴다.

## 검색 방법
/ 일본어 업계 용어로 검색한다. 한국어 관광 블로그는 보조 자료로만 쓴다.
/ 검색어 예시는 references/search-terms.md를 본다.

## 산출물 양식
/ 저장 위치: 리포지토리 benchmark/ 폴더. 파일명은 각 에이전트 지시를 따른다.
/ 파일 맨 앞: 우선순위 요약표(순위, 브랜드, 유형 A/B/C, 매장 수, 방문 추천 매장, 한 줄 시사점).
/ 그 뒤: 브랜드별 상세.
/ 맨 끝: 조사하지 못한 것, 확인이 필요한 것.
/ 글머리 기호는 "/"를 쓴다. 가운뎃점은 쓰지 않는다.
/ 문서 논조: 깎아내리지 않는다. 사실만 남긴다.
