# 현장 관찰 체크리스트 (매장마다 같은 양식으로 적는다)

## 기본
/ 방문 일시(요일, 시각), 입점 시각, 퇴점 시각(영수증 시각으로 확인)
/ 브랜드, 매장명, 입지 유형(노면, 상업시설, 데파치카, 역사, 공항)

## 공간과 운영
/ 좌석 수(대략), 카운터석 여부, 테이크아웃 동선 유무
/ 대기 줄 길이와 대기 시간
/ 홀 인원, 주방 인원(보이는 만큼)
/ 오픈키친, 조리 시연 여부와 방식
/ 주문 방식(테이블, 키오스크, 카운터, 모바일)

## 상품과 가격
/ 메뉴 수(메인 기준), 시그니처 메뉴
/ 시그니처 가격, 내가 낸 금액, 세트 구성
/ 시그니처 주문 비율(주변 테이블 몇 곳 중 몇 곳)
/ 메뉴판, 패키지, POP 사진

## 아모제 대입
/ 자문밖, 오므토토마토, 카페아모제 중 어디에 대입할 요소인가
/ 그대로 가져올 것, 바꿔서 가져올 것, 못 가져올 것
/ 한 줄 메모
